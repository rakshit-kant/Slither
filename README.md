# Slither

A Simple Snake TUI Game made using Rust.

## Features

It is just a Snake Game which we all played in Nokia Smartphones in our Childhood.

The Only Thing different here are:

* Made using Rust (instead of C in Nokia Phones)
* Has Keyboard Compatibility
* Is a Terminal Program
* Has some different Advanced Levels and Modes
* Has an Eye Candy TUI

## Uses of Slither

To Be Honest... I would use it in my Leisure Time to cherish my Childhood Time.

## Requirements

* Rust Compiler
* Cargo (Quality of Life (QoL) Requirement)

## Usage/Running

### By just cloning the Repo and doing it Simply

```bash
git clone https://github.com/rakshit-kant/Slither.git
cd Slither
cargo run
```

Then Play as you want.
